# Architecture Decision Records

This folder holds Architecture Decision Records (ADRs) for major ComfortOS product and engineering decisions.

Use ADRs when a decision changes architecture, provider strategy, routing behavior, data ownership, product semantics, or design-system direction. Do not use ADRs for routine implementation notes.

Suggested filename format:

```text
ADR-001-map-renderer.md
ADR-002-routing-engine.md
ADR-003-weather-provider.md
ADR-004-building-data-provider.md
```

Suggested structure:

```text
# ADR-000 — Title

Date:
Status: Proposed | Accepted | Superseded

## Context
## Decision
## Consequences
## Alternatives Considered
```

No ADRs are accepted in this documentation setup task beyond the principles already established in `docs/architecture/ARCHITECTURE_SPEC_V1.md` and `docs/design/DESIGN_GUIDELINES.md`.
